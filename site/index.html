The tour

01

Projects, not tabs

Every folder gets a color, its own terminals and a ±N chip for uncommitted work. Close the browser; the shells keep running.

02

Agents side by side

Claude Code, Codex, Gemini, Devin and more get an AI chip with the model and how full the context window is.

03

It knows when they need you

Only when an agent asks something: an amber chip, a chime, and a toast or desktop notification.

04

Context that outlives the agent

Task, next step, facts, decisions and recent activity per project. A new agent runs sd context and continues.

Everything else

The rest of your workday, built in.

Git at a glance

Changed files with diffs, the full commit graph, one-click checkout.

Command palette

CtrlShiftP for every command.

Ask at the prompt

Task manager

CPU, RAM and GPU per terminal, with agents and ports.

Search every terminal

Scheduler

Scratchpad

Markdown notes. Agents add with sd notes.

Bookmarks and history

Saved commands, and every command with exit code and duration.

Radio

cliamp channels in the top bar, streamed by your browser.

Machines

SSH machines and RDP desktops next to your local shells.

Agents as a team

Agents that talk to each other.

Each terminal has a name. From inside one, an agent can list the others, read their screens, type into them, spawn a sub-agent in a new pane or hand off work and get told when it's done. shelldeck installs a skill so agents know these commands.

  • Hooks for Claude Code, Codex, Gemini and Devin report working, blocked and done exactly
  • A sub-agent's questions go to its parent, not to you
  • Sessions can be resumed after a restart

Anywhere

      
On your PC. And your phone.

    

    

      

        
        
Share in one click
A Cloudflare tunnel with a one-use link, valid for 10 minutes. The device waits until you allow it, after matching a 4-digit code.

      

      

        

        
iPhone and iPad app
End-to-end encrypted with X25519 and AES-256-GCM, so Cloudflare and your Wi-Fi only see ciphertext.

      

      

        
        
Four panes on iPad
Projects in a sidebar, up to four tiled terminals beside it.

      

      

        
        
One device at a time
A password is mandatory. Devices lists every signed-in browser and signs them out.
